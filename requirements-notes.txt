# requirements.txt 的**中文注释**（★ pip 不读本文件）
#
# ★★ 为什么放在这里
# ★ `pip install -r requirements.txt` 在**中文 Windows** 上用 **GBK**
#   解码该文件 ⇒ 若里面有非 ASCII 字符 ⇒
#   `UnicodeDecodeError: gbk codec ... illegal multibyte sequence`
#   ⇒ **exit code 2** ⇒ 启动器报 "UPDATE FAILED"。
# ⇒ 所以 `requirements.txt` **必须保持纯 ASCII**，
#   任何中文说明都放本文件。
#

## 真因（通用，不只御灵之境）
  * switch_soul_config.switch_group_team 出厂默认 = '-1,-1'
  * 用户只勾「启用」没设组/队 => 值就是 '-1,-1'
  * 实测 switch_parser('-1,-1') => (-1,-1)  ★ 解析成功, 不抛
    -> 绕过旧代码唯一的 except ValueError
  * switch_soul_one(-1,-1) -> get_group_assets(-1) 是 dict 下标
    -> ★ KeyError（不是 ValueError）=> 旧 except 抓不住
  * 25+ 个调用方都把 run_switch_soul(...) 写在 try 之外
    (如 GoryouRealm/script_task.py:26-28) => 整局任务被终结
  => 用户体感「御灵之境更换御魂出错, 直接跳过了更换」
